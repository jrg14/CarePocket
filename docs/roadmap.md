# Roadmap

## Estado actual

La rama `main` cubre la base técnica:

- API FastAPI.
- autenticación JWT.
- alta de usuarios.
- lectura del usuario autenticado.
- base de datos async.
- migraciones iniciales.

## Fase 1: base funcional

Objetivo:

- consolidar autenticación y configuración.
- estabilizar la estructura del proyecto.
- mejorar la experiencia de desarrollo local.

Entregables esperables:

- README operativo.
- guía de arquitectura.
- guía de desarrollo.
- entorno Docker estable.

## Fase 2: núcleo financiero

Objetivo:

- introducir el dominio financiero real.

Entregables:

- cuentas.
- transacciones.
- categorías.
- transacciones recurrentes.
- resúmenes financieros básicos.

## Fase 3: inteligencia descriptiva

Objetivo:

- detectar patrones y anomalías.

Entregables:

- concentración de gastos.
- detección de suscripciones.
- identificación de hábitos repetidos.
- alertas sobre variaciones relevantes.

## Fase 4: predicción

Objetivo:

- anticipar cómo evolucionará la situación financiera.

Entregables:

- saldo futuro.
- ahorro futuro.
- tendencias.
- simulaciones básicas de escenarios.

## Fase 5: analítica asistida por IA

Objetivo:

- traducir datos financieros en explicaciones y recomendaciones.

Entregables:

- interpretación de patrones.
- recomendaciones accionables.
- simulaciones más guiadas.
- explicaciones comprensibles para el usuario.

## Fase 6: salud financiera

Objetivo:

- convertir la información en una visión más humana y orientada a mejora.

Entregables:

- puntuación o diagnóstico de salud financiera.
- sugerencias priorizadas.
- seguimiento de mejoras.

## Criterio de priorización

La prioridad lógica parece ser:

1. datos confiables.
2. estructura de dominio.
3. métricas útiles.
4. predicciones.
5. recomendaciones.

Sin una buena base de datos de negocio, la parte de IA se queda sin fundamento.

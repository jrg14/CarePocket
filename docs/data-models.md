# Modelos de datos

Este documento actúa como índice de los modelos del proyecto.

La documentación detallada de cada módulo vive en `docs/features/<modulo>/`.

## Módulos documentados

- [Users](./features/users/overview.md)
- [Ledgers](./features/ledgers/overview.md)

## Convención de la carpeta `features`

Cada módulo debe tener dos archivos:

- `overview.md`: explica el funcionamiento, el cometido y datos relevantes del módulo.
- `models.md`: describe los modelos de datos del módulo y justifica cada campo.

## Estado actual

En la rama `main` existen ya los módulos `users` y `ledgers` como base funcional del backend.

La documentación de futuros módulos seguirá esta misma estructura.
